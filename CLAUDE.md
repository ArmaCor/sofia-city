# Городок Софии

Развивающая веб-игра для пятилетней дочери Владимира — Софии. Играет на iPad
(старом, см. «Железо» ниже) как «приложение» с экрана Домой.

@NOTES.md

Файл выше (`NOTES.md`) — подробный журнал багов, находок и решений,
подгружается автоматически вместе с этим файлом. Этот файл — что и почему
устроено так; NOTES.md — на какие грабли уже наступали и как вылезли.

## Что это за игра

Полная задумка (locations, сюжеты, герои, экономика наклеек/монет) описана
в `Набросок для промта.md` — черновик брифинга, где Владимир впервые
рассказал идею. Из неё пока реализован только **один вертикальный срез**:
мини-игра «выкопай букву».

- Аватар — сама София, героя-технику зовут **Ковшик** (экскаватор).
- Задание: провести пальцем по пунктирной дорожке в форме буквы — Ковшик
  копает котлован. Закончил все штрихи — на месте котлована вырастает дом,
  начисляется монетка и наклейка.
- Реализовано 5 букв: А, О, С, У, М (`src/letters.js`).
- Побеждать нельзя проиграть: прогресс никогда не откатывается назад,
  палец может гулять далеко от линии (щедрый допуск).
- После победы сцена **замирает** (не анимируется), пока ребёнок сам не
  тронет экран — чтобы успеть разглядеть дом, а не быть погнанным дальше.
- Антагонист по задумке — енот Шуруп (пока не реализован).

## Железо и его жёсткие ограничения

**iPad Софии не может обновиться выше iPadOS/Safari 15.6.** Это не гипотеза,
а установленный факт (видно в user-agent при отладке). Отсюда прямые
последствия для кода:

- `vite.config.js`: `build.target: ['es2019', 'safari15']` — обязателен.
  Без него в сборку может проникнуть современный синтаксис (в т.ч. из
  Three.js) вроде `static {}`-блоков классов, который этот Safari не
  распарсит — и весь скрипт молча не выполнится.
- Только **mp3** для звука, не m4a/aac (см. NOTES.md, пункт про звук).
- `SpeechSynthesisUtterance.onend` на этом Safari срабатывает раньше, чем
  реально доигран звук — не полагаться на него для тайминга.
- Safari требует, чтобы `HTMLAudioElement.play()` был вызван **синхронно**
  в том же тике, что и жест пользователя (клик/тап) — иначе тихо
  отклоняет с `NotAllowedError`. Это касается КАЖДОГО отдельного
  audio-элемента, не только первого вызова на странице.
- Ориентация — только альбомная, показываем оверлей «поверни планшет».

Прежде чем менять что-то в звуке, синтаксисе или тайминге — сверься с
NOTES.md, там разбор конкретных багов с этим железом.

## Стек и структура

- **Three.js** (3D-мир, вид сверху-сбоку) + **обычный HTML/CSS поверх** для
  интерфейса (кнопки, оверлеи) — проще делать крупные кнопки для ребёнка,
  чем изобретать их в 3D.
- **Vite** — сборка и dev-сервер. `npm run dev` / `npm run build`.
- Ванильный JS, ES-модули, без фреймворка.

```
src/
  main.js             точка входа: собирает мир, UI, сохранение прогресса
  scene.js             мир Three.js: свет, земля, камера, забор (instanced)
  excavator.js          Ковшик: корпус, гусеницы, стрела, глаза, мигалка
  letters.js             буквы как маршруты (набор штрихов-ломаных)
  task-dig-letter.js      логика мини-игры «выкопай букву»
  voice.js                голос: живые mp3 + запасной синтез речи браузера
  sfx.js                   звуковые эффекты — синтезируются на лету (Web Audio)
  style.css
public/assets/voice/       готовые mp3-файлы голоса (см. ниже)
.github/workflows/deploy.yml   автосборка и деплой на GitHub Pages
```

Прогресс игрока (монеты, наклейки, номер буквы, звук вкл/выкл) хранится в
`localStorage` на самом iPad — никуда не отправляется.

## Голос: как устроено

`src/voice.js` — фразы собираются из **кусочков**, чтобы при добавлении новой
буквы не переписывать всю обвязку:

- `VOICE_FILES` — цельные фразы без буквы внутри (`start`, `stroke.next`,
  `house.default`).
- `LETTER_FILES` — имя буквы как отдельный короткий клип, переиспользуется.
- `VOICE_TEMPLATES` — фразы с буквой внутри (`task.dig`, `win`): массив вида
  `[префикс.mp3, null, суффикс.mp3]`, где `null` — сюда подставляется клип
  буквы.
- Если для реплики нет файла (ещё не записан/не сгенерирован) —
  автоматически звучит `speechSynthesis` браузера. Ничего в коде менять не
  нужно, файл сам подхватится, когда появится на диске под нужным именем.
- Версия файла — **в имени файла** (`start-v5.mp3`), не в `?query`: у
  GitHub Pages кеш на статику 10 минут, а query-параметр в адресе `<audio>`
  на старом Safari сам по себе иногда мешает распознать формат.
- `voice.unlockAudioFiles(onDone)` — обязательно вызывать синхронно в
  обработчике первого тапа («Играть»), и именно **в один синхронный проход**
  по всем файлам разом (см. NOTES.md про гонку с жестом пользователя).

## GitHub / деплой

- Репозиторий: **`github.com/ArmaCor/sofia-city`** (аккаунт **ArmaCor**, не
  `vladimir346` — та учётка Владимиру не принадлежит, доступа нет).
- `gh` CLI на этом Маке авторизован как ArmaCor, со scope'ами
  `repo,workflow,read:org,gist`. Если авторизация слетит — логиниться
  заново на ArmaCor, не пытаться восстановить vladimir346.
- Пуш в `main` → `.github/workflows/deploy.yml` сам собирает (`npm ci &&
  npm run build`) и публикует `dist/` на GitHub Pages.
- Живой адрес: **https://armacor.github.io/sofia-city/**
- После пуша: подождать деплой и проверить —
  ```
  RUN_ID=$(gh run list --repo ArmaCor/sofia-city --limit 1 --json databaseId -q '.[0].databaseId')
  gh run watch --repo ArmaCor/sofia-city "$RUN_ID" --exit-status
  ```
- На iPad игру ставят на экран Домой через Safari → Поделиться → «На экран
  Домой» — открывается как отдельное приложение, без адресной строки.

## Как проверять правки перед пушем

1. `node --check src/<файл>.js` на каждый изменённый файл.
2. `npx vite build` — должен собраться без ошибок (предупреждение про
   >500KB chunk — норм, three.js тяжёлый, пока не разбивали).
3. Коммит, пуш в `main`, дождаться деплоя (см. выше).
4. Попросить Владимира **полностью закрыть игру и открыть заново** на
   iPad перед проверкой — но помнить, что это не всегда сбрасывает
   HTTP-кеш (см. NOTES.md).

## Временное: панель отладки звука

В `index.html` есть `#voice-debug` — маленькая тёмная панель в левом нижнем
углу экрана, и в `voice.js` — функция `log()`, которая туда пишет. Это
осталось от отладки звуковых багов на реальном iPad (без кабеля/Мака видно
прямо на экране). **Убрать**, когда голос окончательно стабилизируется и
Владимир подтвердит, что больше не нужна.
